# Atliq-hospitality-project
End-to-end hotel analytics project for AtliQ Grands (25 properties, 4 cities), built in Excel, SQL, Tableau and Power BI. Two-page report: Booking Performance &amp; Leakage (revenue, RevPAR, ADR, occupancy, cancellations) and Weekly/Day-wise trends. Found ~15% revenue lost to cancellations and no-shows, with similar cancellation rates on all platforms.
